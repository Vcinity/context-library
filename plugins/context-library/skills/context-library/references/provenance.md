# Provenance

Use three labels when describing record quality:

- `explicit`: the transcript directly rendered a decision.
- `inferred`: the register synthesized intent from adjacent discussion.
- `assumed`: a best-effort interpretation that should be treated cautiously.

## Evidence Rules

- Keep timestamps when they are known.
- Name the decisionmaker when the transcript makes it clear.
- Note older decisions that are superseded.
- Do not overstate certainty when the transcript is thin.
